# Personal Finance 360

A comprehensive personal finance and budget tracking dashboard built with **React**, **Tailwind CSS**, and **Recharts**.


## Features
- **Dashboard & Analytics**: Real-time KPI summaries (Total Income, Total Expenses, Net Savings) with interactive charts powered by Recharts[cite: 6, 7].
- **Transaction Management**: Complete CRUD operations with search, category filtering, type filtering, and sorting[cite: 6, 7].
- **Monthly Budgets**: Set spending thresholds per category and track real-time utilization percentages with threshold indicators[cite: 6, 7].
- **Savings Goals**: Create financial targets with automatic percentage tracking and deposit simulation[cite: 6, 7].
- **Spending Insights (Derived State)**: Real-time dynamic analysis including highest spending category and overall budget usage calculation[cite: 7, 8].
- **Data Persistence**: Automatic sync with browser `localStorage`.

## Tech Stack
- **Framework**: React (Vite)
- **Styling**: Tailwind CSS
- **Icons**: Lucide React
- **Data Visualization**: Recharts
- **Routing**: React Router DOM
